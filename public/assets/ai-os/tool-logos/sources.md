## Deliberately text-only

- Obsidian: The public website uses a linked plain-text tool name. Obsidian's official brand guidance asks users to contact the company for commercial use of its marks, so the downloaded prototype mark is not included in the production website assets.
- GBrain: The first-party project is https://github.com/garrytan/gbrain at revision https://github.com/garrytan/gbrain/tree/a6be012a3bcfac42e279630aedec5cda4a450e29. Its tracked files do not publish a standalone product logo, and https://gbrain.io/ does not provide a brand-resource download. No generic brain icon or inferred mark was substituted.
- SharePoint: Microsoft's official architecture icon collection is published at https://learn.microsoft.com/en-us/microsoft-365/solutions/architecture-icons-templates, but Microsoft limits that collection to architecture diagrams, training materials, and documentation. A marketing landing page falls outside that stated scope, so no SharePoint icon was copied.

## Asset integrity checks

- All seven included SVG files parse as XML.
- No SVG contains a script element, `javascript:` URI, `foreignObject`, external `href`, `xlink:href`, remote CSS URL, or CSS `@import`.
- The OpenAI asset was rendered and visually checked as one centered black Blossom with the supplied clear space, without construction guides or additional artwork.
- The included files match their downloaded first-party source bytes. The Hermes Agent raw endpoint later returned a GitHub rate-limit response during the repeat fetch; its saved file retains the source hash recorded when it was originally downloaded.
- No asset was redrawn, recolored, optimized, or passed through a third-party icon library.
